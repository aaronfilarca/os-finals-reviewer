# OS Finals Reviewer

The published website contains 212 operating system practice questions across 11 modules, with stacked choices, immediate feedback, explanations, shuffled questions, and retry for incorrect answers.

For questions with multiple answers, one incorrect choice marks the attempt wrong immediately. Selecting every correct choice marks it correct. There is no check-answer button.

GitHub Pages serves the ready-to-use website in `docs/` on the `main` branch. Open `docs/index.html` to use it offline. Browser progress is saved on the current device.

This repository contains only the files used by the website. The original reviewer text, development dependencies, and development scripts are retained locally.

## Applied AI Finals Practice

[Open the AI reviewer](https://aaronfilarca.github.io/os-finals-reviewer/applied-ai/) or [download the 200-question JSON](https://aaronfilarca.github.io/os-finals-reviewer/applied-ai/questions.json).

The `docs/applied-ai/` section contains 200 original practice questions based on the EECE101/AIE10 final-exam announcement and course guides. Four 50-question practice sets mirror the announced format: 20 single-answer questions, 5 select-all, 15 true/false, and 10 typed blanks per set. Answers, explanations, sources, module filters, and saved progress are included. These are preparation questions; actual exam content may differ.

The AI reviewer has its own saved progress and a separate page from the existing Operating Systems reviewer. Read [the announcement analysis and source notes](docs/applied-ai/README.md) for scope and study priorities.
